Is the new user message a correction?

A correction is a message in which the user tells the agent that what it said, did or assumed is not what the user meant. The user may say so outright ("no, I meant...", "that's not what I asked") or show it by restating the request differently from how the agent took it.

A message that only adds a new request, asks a question, approves, or changes direction for a reason of the user's own is not a correction.
