Decide whether the user's newest message pushes back on the agent's own work.

Count it when the user says, outright or by implication, that something the agent wrote, did, assumed, planned or built misses what the user meant or wanted, or gets the facts wrong. This holds however the user puts it: "no, I meant", a pointed question about something the agent should have done, restating the request in a way that shows it was misread, a remark in passing inside a longer message, a joke, or a complaint that the agent keeps doing something. Also count it when the user turns down or reshapes a plan the agent proposed and gives a reason of their own, says they cannot follow what the agent wrote (even if they blame themselves), objects to something they had approved, or asks whether the agent got something wrong and what came before shows it did. If any part of the message does this, the message counts.

Do not count it when the user answers the agent's question or picks one of its options without objecting to its advice; changes their own mind after the agent did what was asked; fixes their own slip before the agent acted on it; asks for something new or for more of the same; wants a longer, deeper or differently shaped result; reports that something fails without blaming the agent; asks whether the agent got something wrong when what came before shows it had not; asks a question to learn something; vents about a tool, a service, other people or the work itself; or approves, thanks, or says go.

Judge only the newest user message. What came before it is there to show what it answers.
