Is the user's newest message a correction?

The user directs an AI coding agent. A message is a correction when the user tells the agent that something the agent said, did, assumed, proposed or produced is not what the user meant or wanted. It points back at the agent's work: a reply, a reading of the request it acted on, a plan, a file, an action taken or skipped, a claim, a standing rule of the user's it broke, a habit it keeps repeating, or earlier work it is carrying forward. The form does not matter. It can be blunt or polite, a statement or a question ("did you check X?" when the agent should have), a re-explanation that shows the agent misread the request, an aside inside a long message about other things, a joke, or a complaint about how the agent keeps behaving. One corrective part makes the whole message a correction.

These are corrections too:
- Declining, reshaping or putting conditions on a plan or recommendation the agent made, with a reason of the user's own.
- Saying they cannot follow what the agent wrote, or asking it to explain again, even when they blame themselves.
- Objecting to something the user had approved earlier.
- Asking whether the agent did something wrong, when what came before shows it did.

These are not corrections:
- Answering the agent's question, or picking one of the options it offered, with no objection to its recommendation.
- Changing their own mind after the agent did what was asked.
- Fixing their own slip before the agent acted on it.
- A new request, or extending the work ("also do X", "now do Y").
- Asking for more, deeper, or a different form of output than the agent delivered.
- Reporting that something does not work, without saying the agent was at fault.
- Asking whether the agent did something wrong, when what came before shows it had not.
- A question asked to learn something, with no gap in the agent's work behind it.
- Frustration at a tool, a service, other people, or how hard the work is.
- Approval, thanks, or "go".

Judge only the newest user message. What came before it is there to show what it answers.
