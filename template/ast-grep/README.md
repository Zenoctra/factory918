# ast-grep rules

One rule engine for opinions that should hold in more than one language. `ast-grep scan` runs in CI (Check job); `ast-grep test` validates the rules against `rule-tests/`. Add a rule only from a ledger entry that has recurred; ceilings for old code are a ratchet script, not a rule option. TypeScript-only rules belong in `oxlint-plugin-project/`.
