# Toolchain: Vite+ (`vp`) on pnpm and Node 24

We standardise on Vite+ as the single toolchain: `vp fmt` (Oxfmt), `vp lint` (Oxlint), `vp check`, `vp test` (Vitest), `vp build`, `vp hooks`/`vp staged` for git hooks, pnpm underneath, Node 24. Versions pinned on 2026-09-16: vite-plus 0.3.1, @oxlint/plugins 1.82.0, @ast-grep/cli 0.45.3, Node 24.21.0 and pnpm 12.3.4 selected per project by the Vite+ node manager. `/factory-start` updates this line from `vp --version`, `node --version` and `pnpm --version` when they move. Because every hook, CI job and skill names these commands, changing the toolchain is a repo-wide change: hard to reverse, surprising without context, and a real trade-off (one vendor's cadence versus assembling Prettier + ESLint + tsc + Vitest ourselves).
