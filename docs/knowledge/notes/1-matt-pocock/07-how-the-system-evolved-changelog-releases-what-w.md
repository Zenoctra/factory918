## How the system evolved (CHANGELOG + releases; what was removed and why)

Timeline (dates from the [releases page](https://github.com/mattpocock/skills/releases), aihero.dev post dates, and secondhand metrics):

- **~Feb 2026 — repo starts** as "Straight from my .claude directory"; by 2026-05-02 a reviewer counts "53,742 stars... ~90 days" ([andrew.ooo](https://andrew.ooo/posts/matt-pocock-skills-claude-code-review/), secondhand). Pre-1.0 skill names: `write-a-prd`/`to-prd`, `to-issues`, `github-triage`, `diagnose`, `caveman`, `zoom-out`, `ubiquitous-language`, `design-an-interface`, `write-a-skill`. The [DeepLearningAI fork](https://github.com/DeepLearningAI/Claude-Skills) is a frozen snapshot of this era (still lists `to-prd`, `to-issues`, `caveman`, `obsidian-vault`); it is not maintained and should not be used as a reference.
- **2026-03-16 / 03-23** — "5 Agent Skills I Use Every Day" and "My 'Grill Me' Skill Went Viral". Original grill-me: "Interview me relentlessly about every aspect of this plan until we reach a shared understanding... If a question can be answered by exploring the codebase, explore the codebase instead. For each question, provide your recommended answer." ([aihero.dev](https://www.aihero.dev/my-grill-me-skill-has-gone-viral))
- **2026-04-28** — issue #89: build `setup-matt-pocock-skills` and "migrate engineering skills to vague prose" (tracker becomes config, not hard-coded `gh` commands) ([issue #89](https://github.com/mattpocock/skills/issues/89)).
- **2026-04-30** — `ubiquitous-language` folded into `grill-with-docs`; `ubiquitous-language.md` becomes `context.md`; ADRs added ([changelog post](https://www.aihero.dev/skills-changelog-ubiquitous-language-grill-with-docs)).
- **2026-06-17 — v1.0.0.** Adds `ask-matt`, `codebase-design`, `domain-modeling`, `resolving-merge-conflicts`; renames `diagnose` → `diagnosing-bugs`; replaces `write-a-skill` with `writing-great-skills`; exposes `grilling` as a model-invoked primitive; removes `caveman` ("a duplicate of another skill I was testing and was never meant to be public") and `zoom-out` ("went unused in practice"); introduces the "User-invoked / Model-invoked" taxonomy replacing "Commands / Skills". v1.0.1 same day: `teach` reuse-first. ([CHANGELOG.md](research/1-matt-pocock/skills-repo/CHANGELOG.md))
- **2026-07-08 — v1.1.0.** `to-prd` → `to-spec` ("wasn't actually a PRD"); `to-plan` + `to-issues` → `to-tickets` (old name "biased towards GitHub and Linear"); `review` → `code-review` with the Fowler baseline; `decision-mapping` → `wayfinder` (graduated; "Plan, don't do"; map moved onto the tracker; HITL/AFK classification "fixes students' reports of `/wayfinder` grilling _itself_"); `research` added; `prototype` made model-invoked; `tdd` reshaped "into a reference-only skill" dropping the refactor stage; grilling gains a confirmation gate and the facts-vs-decisions split; triage learns external PRs. ([CHANGELOG.md](research/1-matt-pocock/skills-repo/CHANGELOG.md), [v1.1 post](https://www.aihero.dev/skills/skills-changelog-v1-1-wayfinder-to-spec-to-tickets-grilling-improvements))
- **2026-08-05 — v1.2.0 (+1.2.2 same day; 1.2.3 on 08-06).** Ships as a Claude Code plugin (accepted into the official marketplace the same day); Codex `openai.yaml` sidecars; `AGENTS.md` symlink; graduates `to-questionnaire` and `wizard`; adds `wait-what`; renames `writing-great-skills` → `writing-for-agents` (model-invoked); `grilling` moves to round-by-round frontier questioning; `prototype` becomes a shareable HTML file and prototypes are kept on branches; wayfinder "decision tickets" with parallel research subagents; `ask-matt` gains phase boundaries (handoff "oversold", compact "the default, not the first reach", smart zone 120k→150k); improve-codebase-architecture gains the YAGNI filter; setup made friendlier; local tickets become one file per ticket; six skills removed and the `personal/` bucket deleted. 1.2.2 fixed `writing-for-agents` being invisible to Codex; 1.2.3 added secret redaction to `diagnosing-bugs`, harness-neutral sub-agent wording, and removed wizard's time estimate. ([CHANGELOG.md](research/1-matt-pocock/skills-repo/CHANGELOG.md), [v1.2 post](https://www.aihero.dev/skills/skills-changelog-v12-wait-what-writing-for-agents-claude-code-plugin-and-more))
- **Unreleased as of 2026-08-24 snapshot** ([.changeset/](research/1-matt-pocock/skills-repo/.changeset)): `implement-spec` beta added; `domain-modeling` trigger broadened; cross-skill invocation standardised on "Call the Skill tool with ..." (fixes #453); user-invoked skills no longer "called" by other skills (setup pointers reworded; diagnosing-bugs' hand-off removed); repo-wide em-dash removal (PR #905) and a follow-up YAML fix because "An unquoted colon-space left over from the em-dash sweep... made each block invalid YAML, so `skills.sh` skipped all six during discovery"; `wait-what` follows `CONTEXT-MAP.md`; grilling round template separates questions with `---`.

**Cadence:** minor releases roughly monthly (Jun 17 → Jul 8 → Aug 5), patch releases within days, and a steady flow of docs re-syncs between. Release is automated by changesets (`chore: version skills` PR, then tag). The plugin only updates when Anthropic's official listing moves its pinned sha (ADR 0002), so plugin users lag `main`.

**Pattern in the removals:** nothing was removed for being wrong; things were removed for being duplicated, unused, personal, or better expressed inside a shared reference skill. The direction of travel is a five-step spine plus a small vocabulary layer, with experimentation pushed into `in-progress/`.
