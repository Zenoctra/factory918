## 11. Glossary of tools named here

Vite+ (`vp`): the unified JavaScript toolchain from VoidZero; Vite: the dev server and bundler; Rolldown: its Rust bundler; Vitest: the test runner; tsdown: library bundling; Oxlint: the Rust linter; Oxfmt: the Rust formatter; Vite Task: the task runner (`vp run`); pnpm: the package manager underneath; tsc / tsgo: the TypeScript type checker (tsgo is the native-Go port); Husky and lint-staged: the older way to run git hooks and staged-file commands (Matt's skill); dependency-cruiser: an import-boundary linter (Matt's beta skill); `gh`: the GitHub CLI; `jq`: the JSON tool the hook scripts use; osv-scanner: a dependency-vulnerability scanner (a later rung); Macroscope, Greptile, CodeRabbit, Bugbot: hosted AI review bots (rung 2, when you want one). Added in v2: `uv` (Python project, lockfile and interpreter manager); `ruff` (Python linter and formatter); `pyright` (Python type checker) and `ty` (Astral's, in beta); `pytest`; `uv audit` (dependency vulnerability scan); `ast-grep` (structural code search and lint across languages); Expo (the managed React Native toolchain) and EAS (Expo's cloud build service); Metro (React Native's bundler); the Expo fingerprint (a hash of the native runtime; if it changes, the app needs a store build, not an over-the-air update); Maestro (YAML-driven mobile e2e flows); `xcrun simctl` and `adb` (iOS simulator and Android device CLIs used for screenshots).
