# Ras Mic (Michael Shimeles) — skills

His skills repo has no LICENSE file, so it is not copied here. Clone it yourself:

    git clone https://github.com/michaelshimeles/skills.git ras-mic-skills

What is in it (as of 2026-09-03): `AGENTS.md` (the four-beat router), and seven skills:
`new-feature`, `code-structure`, `evidence-driven-testing` (his own);
`greploop`, `greploop-apps` (vendored from greptileai/skills, MIT), `before-and-after` (vendored from vercel-labs),
`unslop` (vendored from cursor/plugins pstack, MIT, with the trigger rewritten to auto-fire).

Install one the way his README says:

    cp -r code-structure ~/.claude/skills/

Related repos read for the research notes: https://github.com/michaelshimeles/ralphy (the abandoned loop tool),
https://github.com/boringcomputers/nehemiah and https://github.com/michaelshimeles/adam (how he actually builds with agents).
See `notes/4-ras-mic.md` for the full analysis and verbatim excerpts.
