## Design

Posted by the agent 2026-09-22. Synthesized from two architect runners (Claude Opus 5.5 and Claude Opus 5); the base is the first runner's single-file shape, with one-to-one matching and the replicate spread grafted from the second.

### Facts the design rests on (probed 2026-09-22)

- The standalone Claude CLI on this machine is not logged in, so no script can run a Claude model. Claude runs go through the session's native `Agent` tool; their tokens and wall clock are read from the subagent transcript (`.message.usage`, `.message.model`, `.timestamp`), since the tool's own result does not split input, output and cache.
- Codex 0.154.0 with a ChatGPT account refuses `gpt-6-terra` and `gpt-6-sol` with HTTP 400 ("not supported when using Codex with a ChatGPT account") and serves `gpt-6-astra`. Terra and Sol run anyway and land as `unavailable-model` dropouts with the runner's receipt; `gpt-6-astra` is measured as the GPT-6 model this account is served.
- Fable 5.1 is withheld by the operator's rule of 2026-09-22 ("never launch Fable"); it is recorded as a `withheld` dropout until Manuel lifts that rule for this measurement.
- A label is a hard finding only: an item the historical report put under `## Would break` or `## Fails open` that was fixed, or whose `hole:` restarted the rounds (kind `hole`). One label per axis that reported it.

### Usage

```
python3 tests/eval/reviewer/reviewer.py check [--list]
    Validate the fixture set; calibrate every label against the historical report where one survives.
    --list prints the 24 brief ids.
python3 tests/eval/reviewer/reviewer.py run <descriptor> <round>/<axis> <N>
    Ensure runs 1..N exist. A Codex model is dispatched through pstack-runner and scored here.
    A Claude model prints one JSON launch line per run for the session to pass to Agent.
    A withheld model gets a dropout receipt.
python3 tests/eval/reviewer/reviewer.py collect
    Collect every finished Claude run; list what is in flight, unlaunched or stuck. Safe to repeat.
python3 tests/eval/reviewer/reviewer.py table
    Rescore every collected report from the raw files; write scores.tsv and table.md.
```

Descriptors: `claude:sonnet` (Agent `general-purpose` with `model: sonnet`), `claude:opus-5` (Agent `tier-lower`; the transcript's model must be `claude-opus-5`), `claude:opus-5.5` (Agent `tier-upper`; `claude-opus-5-5`), `claude:fable-5.1` (withheld), `codex:gpt-6-astra`, `codex:gpt-6-terra`, `codex:gpt-6-sol` (pstack-runner, effort `medium` on Standards and `high` on Spec, from the models sheet's reviewer rows). Brief ids are `<round>/<axis>` over the rounds `pr94-r1 pr94-r2 pr94-r3 pr96-r1 pr96-r2 pr96-r3 pr99-r1 pr99-r1b pr99-r2 pr101-r1 pr102-r1 pr102-r2`.

Each run gets its own exported tree of the reviewed head (an archive extract with no `.git`) under `${TMPDIR}/review-work/<nonce>/factory918`, with the round's review files copied in. The prompt is the organic one `spec-review` uses: "Read `<checkout>/<review dir>/<axis>-brief.md` whole and follow it. You are working in `<checkout>`; every relative path in the brief is relative to it." No path or prompt the reviewer sees contains `eval`, `test`, `judge`, `score`, `benchmark`, `candidate`, `rubric`, `experiment`, `compare` or `arena`.

### Signatures

```python
Axis = Literal["standards", "spec"]
@dataclass(frozen=True) class BriefId: round: str; axis: Axis
@dataclass(frozen=True) class Brief: id: BriefId; head: str; files: Path; report_relpath: PurePosixPath
@dataclass(frozen=True) class Label: brief: BriefId; id: str; kind: Literal["fixed", "hole"]; anchors: tuple[re.Pattern, ...]  # >= 2, all must match
@dataclass(frozen=True) class Fixtures: briefs: Mapping[BriefId, Brief]; labels: Mapping[BriefId, tuple[Label, ...]]
Route = Native(agent: Mapping[str, str], expect: re.Pattern) | External(slug: str) | Withheld(reason: str)
MODELS: Mapping[str, Route]
@dataclass(frozen=True) class RunId: descriptor: str; brief: BriefId; k: int      # dir: runs/<slug>/<round>/<axis>/<k>
@dataclass(frozen=True) class Prepared: run: RunId; nonce: str; checkout: Path; prompt: str   # run.json
@dataclass(frozen=True) class Tokens: input: int; cache_read: int; cache_write: int; output: int  # input excludes cache reads
@dataclass(frozen=True) class Receipt: run: RunId; status: Literal["complete", "dropout", "contaminated"]; detail: str
    reported_model: str | None; model_verified: bool; effort: str | None; tokens: Tokens | None; wall_ms: int | None; source: Path
Failure = Literal["no-report", "no-count-line", "count-exceeds-items", "no-hard-headings", "timed-out", "child-failed", "malformed-output"]
@dataclass(frozen=True) class Item: n: int; hard: bool; text: str
@dataclass(frozen=True) class Score: run: RunId; failure: Failure | None; hits: frozenset[str]; demoted: frozenset[str]; unlabeled: int; labels: int
class Refusal(Exception)   # stderr "reviewer: <msg>", exit 1, raised before any write

def load_fixtures(root: Path, repo: Path) -> Fixtures          # the only parser of committed input
def parse_report(text: str | None) -> list[Item] | Failure     # pure
def score(run: RunId, parsed: list[Item] | Failure, labels: tuple[Label, ...]) -> Score   # pure, one-to-one matching

def receipt_from_runner(run: RunId, pstack: dict) -> Receipt | Failure                     # pure
def noise(scores: Iterable[Score], axis: Axis) -> Mapping[str, tuple[float, float, float, float]]  # recall, min_k, max_k, sd

def cmd_check / cmd_run / cmd_collect / cmd_table -> int      # the only I/O
```

Fixture layout: `tests/eval/reviewer/rounds/<round>/round` (key=value: pr, ticket, label as posted, head as 40 hex, head_source recorded|inferred|recovered), `rounds/<round>/review/` (the two briefs byte for byte, `diff`, and `<axis>-report.historical.md` where one survives), `tests/eval/reviewer/labels` (TSV: brief, id, kind, anchors joined by ` && `, title), `tests/eval/reviewer/refusals.sh`.

### Contract

- Run state is derived from files, never stored. No directory means absent. `run.json` without `receipt.json` means prepared: a Claude run is then unlaunched, in flight or finished per its transcript, and a Codex run is stuck. `receipt.json` means collected. Creating the run directory is the only guard between two concurrent `run` calls.
- A Claude run's transcript is the one subagent transcript under the project's transcripts directory whose first user message contains the run's nonce. Finished means its last assistant line has `stop_reason: end_turn`. Usage is summed once per `requestId`; wall clock is the last timestamp minus the first.
- Codex `tokens.input` is `inputTokens - cachedInputTokens`, because Codex counts cached tokens inside input (the 2026-09-22 probe reported 15709 input with 12928 cached).
- A report item is a line matching `^\d+\. ` and what follows, up to the next item or `## ` heading. It is hard under `## Would break` or `## Fails open`. Matching reads its normalized text: lowercased, backticks and asterisks removed, whitespace collapsed. A label is hit when a hard item matches all of its anchors; each item claims at most one label (highest anchor count first, ties by item order then label order). A label matched only by non-hard items is demoted: reported, never a hit. A hard item that claims no label is unlabeled, unless it matches a label another item already claimed, which makes it a duplicate.
- A context failure is never zero findings. Recall is hits over labels across a model's complete runs on one axis; a context failure on a labeled brief counts its labels as missed. The noise band is the best model's per-replicate recalls, min to max; a model is within noise when its recall is at least that min.
- Contaminated: a Claude transcript whose Read, Grep, Glob, Write or Edit names a path outside the checkout, whose Grep or Glob has no path, or whose Bash command lacks the checkout path. A contaminated run is kept for reading and left out of every metric.
- Calibration: `check` scores each surviving historical report and requires label `S<n>` or `P<n>` to be claimed by item n and by no other item.

### Tests

`tests/eval/reviewer/refusals.sh` builds a temporary repository, a one-round fixture set, a fake pstack-runner and hand-written transcripts. It asserts one line per cell, in the table's order, then one per scoring rule in the Contract: one-to-one matching, demoted, duplicate, a context failure on a labeled brief, Codex input minus cache, usage once per `requestId`, wall clock, the noise band, and a calibration mismatch.
